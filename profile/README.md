# fxapis

The hosted MetaTrader 5 REST API: connect MT5 accounts by password and trade
them from code, from TradingView alerts, from n8n, or from an AI agent over MCP.
No terminal, VPS or EA on your side.

- **Docs:** https://docs.fxapis.com — quickstart, guides and the API reference
- **SDKs:** [Python](https://github.com/FXapis/fxapis-python) (`pip install fxapis`) ·
  [TypeScript](https://github.com/FXapis/fxapis-typescript) (`npm install fxapis`)
- **AI agents:** [MCP examples](https://github.com/FXapis/fxapis-mcp-examples) ·
  [Claude plugin](https://github.com/FXapis/fxapis-claude-plugins)
- **Automation:** [n8n node](https://github.com/FXapis/fxapis-n8n) ·
  [TradingView, Postman and n8n templates](https://github.com/FXapis/fxapis-integrations)
- **Start here:** [examples](https://github.com/FXapis/fxapis-examples) ·
  [Next.js starter](https://github.com/FXapis/fxapis-nextjs-starter)

Website: https://fxapis.com · Support: support@fxapis.com
